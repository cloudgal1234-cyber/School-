# 🧮 שבילים בכיף

אפליקציית תרגול חשבון בעברית (RTL) לפי ספרי **שבילים 14** ו**שבילים 15** של מט"ח
(כיתה ה'), עם בחירה לפי נושא ותרגול באמצעות תרגילים ומשחקים.

## נושאים

**שבילים 14:** שברים – חלק ב' · ספרות רומיות · מספרים עשרוניים – חלק א'

**שבילים 15:** מספרים טבעיים – חלק ב' · מספרים עשרוניים – חלק ב' · אחוזים ·
ממוצע · מחקר נתונים

כל נושא כולל 3 רמות קושי (קל / בינוני / מאתגר), ושאלות נוצרות אקראית בכל
תרגול כדי שאפשר לתרגל שוב ושוב.

## דרכי תרגול

- **תרגילים** — 10 שאלות ברצף, בקצב חופשי, עם משוב מיידי והסבר לתשובה.
- **מרוץ מהירות** — עונים על שאלות רב־ברירה מהר לפני שנגמר הזמן, עם 3 חיים
  וניקוד לפי מהירות.
- **בלוני תשובות** — לוכדים בלחיצה את הבלון עם התשובה הנכונה לפני שהוא בורח
  למעלה.

התקדמות (כוכבים, רצפים) נשמרת מקומית בדפדפן (`localStorage`).

## Tech stack

- **React 19 + Vite + TypeScript**
- **Tailwind CSS v4**
- **lucide-react** לאייקונים
- **framer-motion** (זמין לאנימציות עתידיות)
- **canvas-confetti** לחגיגת הצלחות
- Web Audio API לאפקטים קוליים ללא קבצים חיצוניים

## הרצה

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בדיקת טיפוסים + build לפרודקשן
npm run lint     # oxlint
```

## מבנה הקוד

- `src/data/topics.ts` — הגדרת הנושאים לפי ספר.
- `src/generators/*` — מחוללי שאלות אקראיות (פונקציה טהורה לכל נושא, 3 רמות
  קושי כל אחד).
- `src/components/screens/*` — מסכי ניווט: בית, בחירת ספר, בחירת נושא, בחירת
  מצב תרגול.
- `src/components/practice/ExercisesSession.tsx` — מצב התרגילים.
- `src/components/games/RaceGame.tsx`, `BalloonGame.tsx` — שני מצבי המשחק.
- `src/hooks/useProgress.ts` — מעקב התקדמות/כוכבים ב-`localStorage`.
